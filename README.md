# Versa Meghalaya Adventure 2026

Single-page trip site for the Versa Meghalaya Adventure (23–27 Sep 2026).

## Live site

Hosted on GitHub Pages: https://pradeepraja-athisaravanan-agilysys.github.io/Annual_trip/

## Adding photos

See [images/README.md](images/README.md) for the exact file names/paths expected
by `index.html` (hero background, place cards, trip gallery). Drop a photo in
place and refresh — no code changes needed.

## Local preview

Just open `index.html` in a browser, or serve it locally:

```bash
python3 -m http.server 8080
```

Then visit http://localhost:8080
